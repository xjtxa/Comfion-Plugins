# Comfion Plugins

[Browse current plugin downloads](https://github.com/xjtxa/Comfion-Plugins/releases)

One current download is retained for each plugin; shared releases remain available for the other plugins. Comfion reads `catalog.json` and verifies package SHA-256 hashes before installation.

Current catalog: seven downloadable plugins. The free local search plugin has been retired.
[NetEase Cloud Music 1.0.0](https://github.com/xjtxa/Comfion-Plugins/releases/tag/netease-1.0.0) replaces the previous NetEase development package. NetEase and QQ chat 0.1.0 require Comfion 0.3 or newer.

The local TTS package contains only its loader, configuration and dependency lockfiles. Downloaded models, caches and user credentials are not included.

Packages include required notices and corresponding source archives.
