# Comfion Plugins

[Download the latest plugins](https://github.com/xjtxa/Comfion-Plugins/releases/latest)

Only the latest plugin release is retained. Comfion reads `catalog.json` and verifies package SHA-256 hashes before installation.

Current catalog: seven downloadable plugins. The free local search plugin has been retired.
NetEase Cloud Music 2.5.4 and QQ chat 0.1.0 require Comfion 0.3 or newer.

The local TTS package contains only its loader, configuration and dependency lockfiles. Downloaded models, caches and user credentials are not included.

Packages include required notices and corresponding source archives.
