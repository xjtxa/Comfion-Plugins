# Comfion Plugins

[Browse current plugin downloads](https://github.com/xjtxa/Comfion-Plugins/releases)

One current download is retained for each plugin; shared releases remain available for the other plugins. Comfion reads `catalog.json` and verifies package SHA-256 hashes before installation.

Current catalog: seven downloadable plugins. The free local search plugin has been retired.
[NetEase Cloud Music 1.0.0](https://github.com/xjtxa/Comfion-Plugins/releases/tag/netease-1.0.0) replaces the previous NetEase development package. NetEase and QQ chat 0.1.0 require Comfion 0.3 or newer.

[Qwen local speech 1.0.0](https://github.com/xjtxa/Comfion-Plugins/releases/tag/local-tts-1.0.0) replaces the previous local TTS development package. It includes the loader, native Q8 TTS engine, optional ASR loader, pinned dependency manifests and licenses (94.24 MB). Python, CUDA dependencies and models download on demand; user recordings, configuration and caches are not included. Use the latest Comfion 0.3 host for streaming playback fixes; the plugin ZIP does not update the desktop player.

Packages include required notices and corresponding source archives.

[Doubao TTS 1.0.0](https://github.com/xjtxa/Comfion-Plugins/releases/tag/doubao-tts-1.0.0) replaces the previous Doubao development package. The default voice is `ICL_uranus_zh_female_bingruoshaonv_tob`; existing custom voices are preserved.
